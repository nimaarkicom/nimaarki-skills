# nimaarki-skills

Original prompts and tool skills used on [nimaarki.com](https://nimaarki.com)'s
[Skills page](https://dfnwhah6bfd5t.cloudfront.net/skills/). One folder per skill.

Each folder has:

- `prompt.md` — the real prompt text, ready to paste into an image or chat model.
- `README.md` — what it does and how to use it.
